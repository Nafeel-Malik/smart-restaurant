# RestoPro — Smart Restaurant Management (Frontend)

React + Vite client for the Smart Restaurant Management System. All restaurant, staff, menu, order, and customer data comes from the NestJS + MongoDB API.

## Stack

- React + Vite
- React Router DOM
- Redux Toolkit
- Tailwind CSS
- Framer Motion

## Getting started

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_URL` should point at the backend (default `http://localhost:5001`).
